FULL GUI LAUNCHER UPDATE
========================

Copy these complete files into the project root:

main/app/app_main.c
main/features/gui_screens/app_ui.c
main/features/gui_screens/app_ui.h
main/CMakeLists.txt

From the project root run:

    idf.py fullclean
    idf.py reconfigure
    ./smart_flash.sh

The launcher starts in normal LVGL mode. Press "Start Camera" to initialize
camera, face detection, and face recognition, then switch to the existing live
camera application. GPIO3 deep-sleep handling remains active.
